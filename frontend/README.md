# frontend
If you want to create your own version of group decision making web application.

You have to check the following folders or file:
- /main.js: Main ligic of the web application and channels between frontend and backend.
- /src/views/: All the interfaces are stored here.
- /src/router/index.js: Define the URL route
- /src/components/: The custome components you can reused.





## Project setup
```
npm install
```

### Compiles and hot-reloads for development
